# 环境坑

- 用 `/usr/bin/grep`（shell 内建会漏匹配）；macOS 无 `timeout`
- `curl` 下大文件会截断 → 必须按 content-length 校验重试
- Cocos 构建退出码可能假失败，看产物不看码
- 全量 `node --test` 要 8-10 分钟，必须 `run_in_background`（前台 exit 137）
- SpaceFight 3 个测试需先编译 TS，走 `npm run test:input` / `test:simulation`，
  **别用 `node --test` 判定健康度**
- xcodebuild 沙箱内需 `-derivedDataPath .workbuddy/tmp/xxx`；Swift 部署目标 macOS 11 时
  `NavigationStack`/`textSelection`/`@Environment(\.dismiss)` 全不可用
- 新增 `.swift` 文件必须手工注册进 `project.pbxproj` 4 处：PBXBuildFile /
  PBXFileReference / group children / Sources
