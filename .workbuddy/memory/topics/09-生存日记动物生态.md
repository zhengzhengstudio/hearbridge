# 09 · 生存日记动物生态（2026-10-23 起）

规范：`docs/superpowers/specs/2026-08-03-survival-diary-wildlife-ground-design.md`（6 步实施顺序）

## 规则唯一真源
`apps/SurvivalDiaryShared/src/wildlife-simulation.js`（CommonJS）
- 位置单位 = **tile**（1 tile = 48 世界单位），区块 16×16
- `createWildlifeState` / `stepWildlife` / `applyWildlifeAction` / `populationKey`
- 内容：`apps/SurvivalDiaryShared/content/{animals,habitats}.json`（12 种动物）
- 事件：`wildlife-events.js` → `createWildlifeEvent`（SHA-256，**必须与服务端一致**）

## 绝不要手抄副本
`node scripts/build_survival_diary_wildlife_bundle.mjs` 生成：
- `website/.../js/vendor/survival-wildlife.js` 浏览器全局 `SurvivalWildlife`（含纯 JS SHA-256）
- `website/.../server/lib/wildlife-simulation.js` 服务端 CommonJS
- `website/.../server/content/{animals,habitats}.json`

**网页端 `js/` 用普通 `<script>` 全局脚本，没有 ES module。**
新增共享能力时走「生成 + 测试比对」，不要手抄（历史上已出现服务端过期快照 360 行 vs 444 行）。

## 网页端接线
- 新增 `js/wildlife-ui.js`（全局 `SurvivalWildlifeUi`）
- `index.html` 里 **契约包必须排在 wildlife-ui 之前**
- `js/game.js`：
  - 分钟分支（与村民/作物同频）调 `ensureState` + `advance`
  - `render()` 里动物以 `kind:'animal'` 并入 `frameVisibleEntities` 统一深度排序（spec §6.5）
  - `pointerup` 先判动物再判资源/实体
- `js/save-schema.js` 的 `MAP_FIELDS` 要加 `'wildlife'`
- **改任何 js 都要 bump `index.html` 里的 `?v=`**（本项目老规矩）

## 坐标换算
- 共享规则：tile；网页渲染：世界单位（×48）
- 网页 chunk 的 `biome[]` = **原始地形群系名**（与 habitats.json 同词表）；
  `baseTiles[].biome` 是 `assetBiome()` 映射后的素材名 —— **别用错**
- 共享规则读 17×17 格点，网页 chunk 是 16×16 tile 中心采样 → 需摊平（只读 ≤15 的格点）

## 行为要点
- 多数动物先**警戒→逃跑**；野猪/蛇/山羊/小型鲨鱼才会反击
- 反击型：先 `threaten`（**3 分钟预警**）+ `wildlife-warning` 事件，下一拍才 `retaliate`
- 夜行性：野兔/野猪/果蝠/陆蟹/蛇（activityWindows = dawn/dusk/night），
  phase 给 'day' 它们会进 resting —— 测行为要用 'night'
- 驯养：连续投喂 3 次（`safeCamp` 必须为 true）才 `tame`
- 掉落：服务端 `deterministicDrops` = `stableDigest({seed,eventId,speciesId,itemId})` 前 8 位十六进制
