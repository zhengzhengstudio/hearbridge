# 08 · 棋盘底图与坐标表同源（2026-10-22 飞行棋专题）

## 背景
yy 连续否了 4 版飞行棋棋盘：
1. 十字被否 → 2. 直接照搬截图被否（"别直接复制"）→ 3. V5 直角方形环被否 →
4. V6 圆角方形环被否（"有点像样了，但还是不行"）→ 最后给真板截图让**参照**。

根因不只是画错，是**底图与坐标表是两套东西各改各的**：
- 底图是照片畸变版（格子贴边）
- 坐标表是另一套内缩几何（最上格 y=16% vs 底图 y≈3%）
- 黄/绿两个机库还放错了角（黄在左下、绿在右上）

## 现在的做法
**一个脚本同时产出底图和坐标表**，坐标是百分比，三端共用同一张 PNG + 同一张坐标表。

### 唯一真源
`HarmonyOS-App/ZhengZhengBoardGamesHarmonyOffline/scripts/gen_ludo_board.py`
- PIL 直接画，800×800，`MARGIN=18`，`CS=(800-36)/15`
- 产物：`ludo_board.png`(md5 `887e0ac785…`)、`coords.json`、`coords.ts.txt`、`ludo_board.html`
- **自动部署**到：鸿蒙离线 media、鸿蒙在线 media、Android `drawable-nodpi/`

### 几何（标准 15×15 Ludo）
cell 记作 `[row, col]`：
- 主跑道 52 格闭环：`(6,1..5)→(5..0,6)→(0,7)→(0..5,8)→(6,9..14)→(7,14)→(8,14..9)
  →(9..14,8)→(14,7)→(14..9,6)→(8,5..0)→(7,0)→(6,0)→回(6,1)`
- **四个内角是对角过渡**（(6,5)→(5,6) 差 1 行 1 列）—— 这是标准 Ludo 画法，**不是 bug**。
- 起飞点 0/13/26/39；13≡1(mod 4) ⇒ 跑道格 `color[i]=PLAYER[i%4]` 时起飞格自动是本方色。
- 归航通道 5 格：红(7,1..5) 黄(1..5,7) 蓝(7,9..13) 绿(9..13,7)；中心为终点。
- 步数模型：0..50 跑道 / 51..55 通道 / 56 终点。落点公式见下。

### 色序（按 yy 的参考图）
**左上红 / 右上黄 / 右下蓝 / 左下绿**
⚠️ 老版 `gen_ludo_board.py` 用的是 (col,row) **转置**几何 + 「左下黄/右上绿」，
跟线上那张图一直对不上 —— 生成器和产物早就不一致了。

## 四处代码必须同改
| 端 | 文件 | 数组 |
|---|---|---|
| 鸿蒙离线 | `ZhengZhengBoardGamesHarmonyOffline/.../Index.ets` | `ludoRouteX/Y`、`ludoHomeX/Y`、`ludoBaseX/Y`、`ludoFinishX/Y` |
| 鸿蒙在线 | `ZhengZhengBoardGamesHarmony/.../Index.ets` | 同上 |
| Android | `MultipleBoardGamesAndroid/.../MainActivity.java` | `LUDO_ROUTE_X/Y` 等 float[] |
| Windows | `ZhengZhengBoardGamesWindows/src/games/ludo.js` | 程序绘制，同参 SIZE=800/MARGIN=18/CS |

落点公式（三端一致）：
```
p < 0        → base[player*4+piece]
0..50        → route[(p + startOffset[player]) % 52]
51..55       → home[player][p-51]
56           → finish[player]
```

## 验证手段（不看图也能验）
1. **几何数值对拍**：node 脚本按 JS 同参算 52 route + 20 home + 16 base 百分比，
   与 `coords.json` 逐个比对 → 必须全等。
2. **跨端渲染对拍**：headless Chrome 渲染 Windows canvas → 与原生 PNG 逐格取色。
   格内均值差 <6/765 即可，差异只应出现在描边抗锯齿与飞机上。
3. **闭环合法性**：`for i in 52: 相邻格曼哈顿距离` —— 应恰好 4 处不等于 1（四个对角内角）。
4. 底图 md5 三端一致：鸿蒙离线 media / 鸿蒙在线 media / Android drawable-nodpi。
