- **Design Read**：editorial/blog（人类+AI 共写），warm editorial + 双身份系统（human 橙 / ai 青蓝），原生 CSS + 克制动效；旋钮 VARIANCE 6 / MOTION 4 / DENSITY 3。
- **体检结论**：整体已过关（自定义暖白底、双色身份、骨架屏、暗色模式、人机徽章、AI 卡片青蓝强调条，非 LLM 默认套路）。强制项要修的 4 处，已全改 `style.css`：
  1. **按钮对比度（WCAG AA 强制，原不达标）**：`.btn-accent` 原用 `human→ai` 渐变+白字，白字压橙色端(~3.3:1)失败；暗色模式 `--accent` 浅橙+白字更糟。改为**实心 `--accent`(#c2410c) 白字(~5.2:1)**，暗色模式改用深色文字(~7.5:1)；渐变只保留在 `.brand-mark` 与 `.hero h1 .grad` 装饰上（更贴合"色彩一致性锁"）。
  2. **占位符对比度（强制）**：`::placeholder` 原 `--text-mute`(~2.8:1) → 改 `--text-dim`(~5.1:1)。
  3. **触感 `:active` 反馈**：加 `.btn:active:not(:disabled){transform:translateY(1px) scale(.985)}`。
  4. **形状一致性锁**：在 `:root` 半径变量上方补了"按钮/输入/胶囊=pill，卡片=22px(lg)，小块=8px(sm)"的文档化规则注释。
- **附带修的真破版**：登录页「使用铮铮通行证登录」蓝色按钮与其下方灰色说明文字重叠遮挡（`.btn` 是 `inline-flex` + `width:100%` 的 `.btn-block` 与块级 `<p>` 行盒交互导致）。根因修法：`.btn-block{display:flex;width:100%}`（改真正块级）+ `.auth-mini` 上边距由 `-4px` 改 `12px`。窄/宽视口截图双重验证已无重叠。
- **说明**：taste skill 的"落地页需要真实图片"规则对 editorial 博客（内容驱动、图随文章来）属合理例外，未强行塞 AI 图；emoji(🦞🤖) 是品牌 playful 定位，skill 允许，未剥离。
- **部署**：本次只动前端 `style.css` + 此前已动 `login.html`/`auth.js`，同步清单已含，需 `node sync_clawblog.js` + 刷新即生效（前端静态直读，无需 pm2 重启）。
