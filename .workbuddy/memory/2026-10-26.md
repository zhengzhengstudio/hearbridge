## 安卓启动图标被误改成系统默认机器人（已修复，v0.1.19）
- **起因**：恢复的 Java 版 Android 源码缺了品牌 `mipmap-*/ic_launcher_foreground.png`，
  而 `mipmap-anydpi-v26/ic_launcher.xml` 仍引用 `@mipmap/ic_launcher_foreground` → AAPT 报错。
  当时的"修复"是**把引用改指向 `@drawable/ic_launcher_foreground`（Android Studio 默认机器人矢量）**，
  于是 v0.1.18 的图标变成了绿色安卓机器人。yy 发现并要求改回。
- **正确修法**：从线上仍在的 `ZhengZhengGlasses-Android-v0.1.17.apk`（用户现装版本）用
  `aapt2 dump badging` 找到 icon=`res/BW.xml`，`aapt2 dump resources` 拿到
  `mipmap/ic_launcher_foreground`=res/{QZ,zr,Em,Lf,as}.png、`ic_launcher`=res/{9w,yn,FS,RJ,o-}.png、
  `ic_launcher_round`=res/{zR,8c,wb,fO,Gc}.png，全部提取回工程对应 mipmap 密度夹；
  重写两份 anydpi-v26 XML 指向 `@mipmap/ic_launcher_foreground`；删掉机器人 drawable 矢量。
  ⚠️ v17 的 hdpi 前景 `zr.png` 只有 48px（异常），改从 432 的 `as.png` 生成 162px。
- **结果**：新包 `res/as.png` 的 sha256 与 v0.1.17 **逐字节一致**（`f56dd9aa…`）；签名仍 `754aa8bf…`（可覆盖安装）。
  版本 bump 到 **0.1.19 / versionCode 20**，新包 57308391B sha `22ad97b5…`，已上传，
  线上 v0.1.19 与 latest 均校验一致，manifest android=v0.1.19 b20，apk 内 icon 指向 `res/BW.xml`（品牌自适应）。
