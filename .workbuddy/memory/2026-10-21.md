## 眼镜「全部 app」根因与修复
- **根因**：Android 原生端 `/api/glasses/catalog`（route=`website/zhengzhengstudio.cn/server/routes/glasses.js:532`）原来只读 `api/data/shop_items.json`（仅 2 条占位），不读 `glasses.zhengzhengstudio.cn/frame-index.json`（474 款含陌森247、excludedFrameIds=156）。Web 有 builtin 兜底所以正常，Android 没有 → 目录残废、看不到陌森。
- **修复**：重写为「frame-index.json 精选(按 excludedFrameIds 过滤) + shop_items 商家项」合并去重，返回 318 款（含陌森247、bug图0）。`server.js:31` 已挂载路由。语法+真实文件模拟验证通过（318/247/0）。
- **图片**：frame-index 的 image/tryOnImage 是相对路径(`assets/merchants/...`)，Web 用 `toAbsoluteAssetUrl()` 拼 `glasses.zhengzhengstudio.cn` 域名。Android 原生 `openNativeCamera` 只传 frameName/type/lensWidth，**不加载商品试戴图**（原生列表 frameRow 也无缩略图），故相对路径不崩 Android。暂未改 API 返回绝对 URL（避免域名前缀猜错导致 404）。

- Mac=WKWebView 加载网页、Harmony 试戴走 WebView → 共享 Web 的 frame-index 数据，已含全部优化（去网格/自适应/陌森/bug下架）。
