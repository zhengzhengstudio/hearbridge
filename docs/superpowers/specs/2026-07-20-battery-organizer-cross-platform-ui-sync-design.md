# 电池收纳器全端 UI 与同步设计

日期：2026-07-20

## 目标

将电池收纳器的 macOS、iOS/iPadOS、Android、HarmonyOS 和 Web 端改造成各平台原生、结构清楚且可离线工作的正式产品。各端共享品牌、数据规则和核心功能，但遵循各自平台的导航、表单和窗口习惯。

本轮同时解决以下已知问题：

- HarmonyOS 常用预设无法点击或点击后不回填。
- 设置、添加电池和库存内容出现在同一长页面。
- 手机窄屏出现输入框截断和横向溢出。
- 修改数量后统计与列表不能立即刷新。
- 离线新增、登录切换或同步失败时可能丢失本地电池。
- 各端视觉、深浅色、图标尺寸和交互状态不一致。

## 信息架构

### 手机

底部导航固定为：

1. 库存
2. 我的预设
3. 设置

新增电池不是底部标签，而是库存页右上角或平台惯用位置的加号按钮。点击后进入独立添加页面或系统 Sheet。

### 平板、2in1、桌面和 Web

使用左侧导航与右侧内容区：

1. 库存
2. 我的预设
3. 设置

内容区工具栏放置添加和刷新命令。macOS 使用系统工具栏和独立设置窗口；iPadOS、HarmonyOS 平板/2in1 与 Web 使用自适应分栏。窗口或视口缩窄后自动退化为手机结构。

### 页面职责

- 库存：首页统计、同步状态、筛选与电池列表。
- 添加/编辑：独立表单，不与设置或库存列表混排。
- 我的预设：系统预设与账户自定义预设分区展示。
- 设置：账号、同步、外观、反馈、隐私和版本信息。

## 视觉系统

- 主色为克制的蓝色；绿色仅用于库存正常、同步成功等正向状态。
- 删除、退出登录和不可逆操作使用红色。
- 浅色模式使用白色与冷灰分区；深色模式使用深灰层级。
- 不使用大面积渐变、装饰性浮层或重复嵌套卡片。
- 统计信息使用紧凑数字栏，数字采用等宽或 tabular figures。
- 电池列表优先显示名称、规格、数量和位置，状态使用小图标与短文字。
- 输入控件沿用平台原生实现，但统一视觉高度、间距、字号和聚焦状态。
- 电池收纳器图标保留现有品牌图形，各平台按商店和系统规范输出纯色底版本。
- 所有手机页面禁止横向滚动和内容溢出；键盘出现时主要操作仍可访问。
- 保留各平台原生滚动边界反馈和按压反馈，并支持减少动态效果设置。

## 添加电池

默认基础信息：

- 常用预设
- 名称
- 品牌
- 数量
- 收纳位置
- 购买日期或“日期不详”

高级信息：

- 型号
- 化学类型
- 容量
- 电压
- 备注

点击系统预设或自定义预设后：

1. 立即显示选中状态。
2. 回填名称、品牌、型号、化学类型、容量、电压和默认收纳位置。
3. 保持在表单中，允许用户继续修改。
4. 不自动创建或保存电池。

## 自定义预设

- 系统预设只读，包括南孚 5 号、南孚 7 号、金霸王 5 号、金霸王 7 号、9V、CR2025 和 CR2032。
- 登录账户可无限添加、编辑和删除“我的预设”。
- 自定义预设可保存名称、品牌、型号、化学类型、容量、电压和默认收纳位置。
- 自定义预设随账户同步至所有端和 Web。
- 未登录时可以创建本地预设；首次登录时与本机库存一起询问是否合并到账户。
- 颜色与图标不是本轮必要字段，避免增加创建成本。

## 本地优先数据模型

界面始终读取本地数据库。新增、编辑、增减数量和删除首先完成本地事务，随后进入同步队列，因此统计与列表必须在操作完成后立即更新。

每条电池和预设至少包含：

- 稳定 UUID
- 所属空间：匿名本机或账户 ID
- 创建时间
- 修改时间
- 本地版本
- 服务端版本
- 删除标记
- 同步状态

删除使用墓碑记录，服务端确认后再清理，避免另一台设备将旧记录重新上传。

## 登录与离线同步

### 已登录离线操作

- 离线新增、修改和删除立即写入本地。
- 操作进入持久化同步队列。
- 恢复网络后自动同步。
- 同步失败时保留本地数据并提供重试，不用空服务端结果覆盖本地库存。

### 未登录后再登录

- 未登录数据保存在独立的“本机库存”空间。
- 登录成功后，如检测到本机库存或本地预设，弹出一次合并确认。
- 用户可选择“合并到账户”或“仅保留本机”。
- 未经确认不得自动上传匿名数据。

### 退出登录

- 账户数据从当前界面隐藏，本机库存重新显示。
- 存在未同步操作时先提示用户同步或稍后重试。
- 不删除服务端数据，也不把账户数据转入匿名空间。

## 同步流程

同步使用增量协议，不使用整库覆盖：

1. 读取本地同步游标。
2. 拉取服务端自该游标后的变更。
3. 将服务端变更按 UUID 和版本合并到本地。
4. 上传本地待同步操作。
5. 接收服务端版本和新游标。
6. 在一个本地事务中更新记录、统计和同步状态。

联网状态下保存前可以先进行轻量增量拉取，但超时不得阻止用户本地保存。冲突默认按字段版本或最后有效修改合并；无法自动合并时保留本地副本并显示“需要处理”，不得静默丢弃。

统一同步状态：

- 已同步
- 等待网络
- 正在同步
- 需要重试

刷新按钮执行完整双向增量同步。自动同步应防抖并合并重复请求，避免顶部状态条抖动。

## 平台实现边界

- Apple：SwiftUI，共享 Store 与同步层；macOS 和 iOS/iPadOS 使用不同导航容器。
- Android：保留原生实现，使用 Material 3 结构与持久化本地存储。
- HarmonyOS：ArkUI 原生 Navigation/Tabs 和自适应断点；拆分当前过大的页面与状态职责。
- Web：保留现有技术栈，使用桌面管理台布局与响应式手机布局，不内嵌其他端页面。
- 服务端：扩展现有电池 API，支持增量同步、版本、墓碑和账户预设；不覆盖现有生产数据文件。

## 错误与空状态

- 首次使用：显示简洁空状态和添加按钮。
- 离线：显示“等待网络”，所有本地编辑保持可用。
- 同步失败：行内说明原因并提供重试。
- 登录过期：保留本地待同步数据，要求重新登录后继续同步。
- 服务端返回空列表：仅表示服务端无记录，不得清空有待同步或更新版本更高的本地记录。
- 预设回填失败：保持表单原值，并显示可恢复的行内错误。

## 验收标准

### 功能

- HarmonyOS 所有系统预设可点击并正确回填。
- 五端和 Web 新增、编辑、增减与删除后，列表和统计无需切页或重启即可更新。
- 飞行模式下新增电池，恢复网络后能够同步且不丢失。
- 未登录数据在登录时只经用户确认后合并。
- 自定义预设可跨端创建、编辑、删除和使用。
- 同步失败或登录过期不清除本地数据。

### 布局

- 手机宽度下无横向溢出、输入框截断或设置页穿透。
- 设置、库存与添加表单不再同时出现在一个长页面。
- iPad、HarmonyOS 平板/2in1、macOS 和宽屏 Web 正确使用分栏。
- 深浅色模式下输入文字、占位文字、边框和状态色均清晰可读。
- 应用图标在桌面、启动器和商店素材中尺寸合适且无透明背景问题。

### 验证

- 各端运行本地构建与现有测试。
- 为同步合并、离线队列、登录迁移和预设回填补充自动测试。
- 使用手机、平板和桌面典型尺寸进行截图检查。
- Web 使用浏览器自动化检查窄屏、宽屏、深色模式和键盘导航。
- HarmonyOS 使用 API 23/24 的手机、平板和 2in1 配置验证布局与深色模式。
