# SpaceFight Cocos 3D 全端重构设计

## 目标

将 SpaceFight 从“网页 Three.js + 各 App 独立 2D 投影”的多套实现，迁移为一套 Cocos Creator 3.8.8 共享的原生 3D 游戏核心。网页、Android、iOS、macOS 和 HarmonyOS Next 使用相同的飞行、镜头、弹道、任务和 HUD 规则；App 不加载网站、不包含 WebView。

## 首个可玩版本

首个里程碑交付一个完整战斗闭环，而不是菜单样机：从机库选择装备，进入连续战区，完成一次包含巡航、接敌、摧毁目标、拾取战利品和返回航站的任务。保留第一人称驾驶舱与第三人称追尾视角切换，并保留五种武器和现有敌机类型。

现有网页版和原生 App 在新核心达到可玩门槛前继续保留，发布时一次性切换，避免线上出现半成品。

## 渲染与世界

- Cocos Creator 3.8.8 负责 Web 与原生端渲染，原生端使用 Cocos C++ 引擎导出。
- 战斗采用完整 3D 坐标、透视相机、真实炮口 Transform、可见弹道和碰撞体。
- 飞行以 yaw/pitch 为主，加入轻度自动回正和滚转反馈，降低手机晕动感。
- 航站、残骸带、敌军哨站和动态遭遇按区块流式复用，不使用固定副本边界墙。
- 首个版本复用并校正现有 GLB 飞船资产；不能通过材质、灯光和轮廓检查的模型不进入发布包。

## 统一操控

### 桌面

- 点击战斗画面后锁定鼠标，鼠标位移直接驱动机头与镜头。
- `W/S` 推进与制动，`A/D` 横移，`Space` 加力，左键开火，右键副武器。
- `V` 切换第一/第三人称，`Esc` 暂停并释放鼠标。
- 输入法组合期间忽略战斗键位；窗口失焦时释放全部持续输入。

### 手机和平板

- 左侧固定推进杆，位置不随首次触点漂移。
- 右半屏使用相对滑动控制机头，不显示第二个摇杆，也不在松手时改变当前朝向。
- 开火、副武器、加力按钮固定在安全区内，支持多指同时移动、瞄准和开火。
- 提供灵敏度、反转 Y 轴、左手布局和按钮缩放；设置在所有本机模式生效。

所有输入源输出统一的 `FlightCommand`：`throttle`、`strafe`、`yaw`、`pitch`、`boost`、`primaryFire`、`secondaryFire`、`cameraToggle` 和 `pause`。

## 横屏规则

- Android 使用 `sensorLandscape`，iOS 仅声明两个横屏方向，HarmonyOS Ability 启动时请求横屏。
- macOS 使用最小 16:9 战斗画布，窗口过窄时保持画布比例并压缩外围菜单。
- 网页在手机竖屏时只显示旋转设备界面；进入全屏后尝试锁定横屏，失败时保持门禁。
- 所有菜单、装备台、暂停页和战斗 HUD 都以横屏安全区为唯一移动端布局，不再维护竖屏游戏布局。

## HUD 与交互

- 战斗画面全屏呈现，HUD 贴近边缘，只显示护盾/装甲、速度、武器、雷达、任务和威胁方向。
- 中央准星来自真实武器射线；炮口未对齐时显示收敛标记，命中时提供短促声音、闪光和震动反馈。
- 装备台使用机体预览、挂点和属性变化，不使用网页式卡片列表。
- 暂停页停止本地模拟和持续输入，并提供继续、设置、重开任务和返回机库。

## 模式与网络

- 单机任务不需要通行证，不发出登录、更新或联机请求。
- 联网模式通过现有 WebSocket 服务传输 `FlightCommand` 与快照，但客户端预测和本地镜头不等待服务器。
- 首个 Cocos 里程碑优先完成单机核心；多人接入只复用同一模拟接口，不建立第二套操控。

## 鸿蒙签名与发布

- 单机包名保持 `cn.zhengzhengstudio.spacefight.hmos.offline`。
- Cocos 导出的 HarmonyOS Next 原生工程接入现有 release `.p7b`、`.cer` 和 `.p12`。
- 构建同时产出签名 HAP 和签名 APP，并用 DevEco `hap-sign-tool verify-app` 校验证书链、Profile 包名和摘要。
- 当前 release Profile 与证书已验证可用，证书有效期至 2029-07-12。
- 联网包名 `cn.zhengzhengstudio.spacefight.hmos` 目前缺少匹配的 release Profile；在材料补齐前不能标记为 signed 或 store-ready。

## 验收

- 电脑鼠标水平移动 100 次不丢失锁定，输入法不会抢走方向键。
- 手机三指同时推进、转向和开火，任一手指离开不会清除其他输入。
- 横竖屏切换、刘海和圆角屏下按钮不越界；竖屏不能进入游戏。
- 第一/第三人称的炮口、准星和实际弹道一致。
- Android、iOS、macOS、Web、HarmonyOS 使用同一组操控参数和任务数据。
- 鸿蒙单机 `.app` 与 `.hap` 均通过签名验证，清单中的大小和 SHA-256 与文件一致。
