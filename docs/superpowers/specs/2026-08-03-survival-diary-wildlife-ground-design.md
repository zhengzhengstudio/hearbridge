# 《生存日记》动物生态与地表分层设计

日期：2026-08-03  
状态：已逐段确认，等待书面规格复核  
范围：共享规则、Web、Android、iOS、macOS、鸿蒙单机版与鸿蒙联机版

## 1. 目标与边界

本阶段解决两个直接影响游戏感的问题：世界没有会活动的动物，地表只像背景图和散落贴片。目标是建立可长期运行、可保存、可离线、可联机校验的海岛生态，并将地表改成具有过渡、微装饰、动态痕迹和可信遮挡的五层结构。

动物不是无限刷新的材料箱，也不是凭空追杀玩家的怪物。多数动物会逃跑；野猪、蛇、山羊和小型鲨鱼只在玩家靠得过近、护巢、受惊或被攻击时反击。游戏允许狩猎、陷阱和捕鱼，也允许对部分动物进行喂食、驯养和繁殖。

本阶段不添加固定结局，不复制其他生存游戏的美术或动物资产，不以单张宣传图替代实际运行生态，不因低配模式删除动物和玩法。

## 2. 选择的总体架构

采用“共享确定性生态规则 + 平台原生渲染 + 联机服务器校验”。

- 动物出生、移动意图、警戒、逃跑、反击、饥饿、归巢、繁殖和种群恢复由共享规则定义。
- Web、Android、Apple 与鸿蒙消费相同动物 ID、栖息地、行为参数和领域事件，各自负责输入、动画、声音与绘制。
- 单机版在本地完整运行，可断网游玩；联机岛由服务器校验伤害、捕获、掉落、驯养、繁殖和种群变更。
- 动物和地表装饰均由世界种子稳定生成；只有影响玩法的状态进入存档。

不采用各端独立规则，因为会导致同一岛屿在不同设备上出现不同动物和任务结果；也不采用全服务器模拟，因为鸿蒙应用市场单机版必须离线完整运行。

动物按栖息地生成，不将十二种随机撒满所有地形。稀有迁徙、巢穴和产卵行为使用区域与季节条件，不使用固定倒计时刷怪。

## 4. 行为、狩猎与种群

每只活动动物包含年龄阶段、生命、体力、饥饿、警戒、归巢点、种群 ID、当前位置、移动意图和驯养状态。行为采用低成本状态机：休息、觅食、饮水、迁徙、警戒、逃跑、威吓、反击、受伤、归巢和繁殖。

昼夜、雨雪、风、温度、火光、噪声、食物、玩家距离、巢穴和幼崽会改变状态。受伤动物会逃跑并留下可追踪痕迹。蛇不会在玩家不可见时无提示造成伤害；高草中的危险通过声音、草叶扰动或短暂轮廓提供预警。

狩猎必须经过接近、追踪、瞄准或布置陷阱、命中、受伤/逃跑、击倒和处理产物，不能靠近后单击直接变成肉。首批支持近战、投矛或远程武器接口、陆地陷阱与钓具；具体高级武器可在后续配方阶段补齐，但领域事件与目标接口本阶段一次定义。

区域种群包含成年数量、幼体数量、繁殖容量、食物承载力、水源可用性和捕猎压力。死亡后不会原地快速刷新。保留水源、植被和繁殖个体会缓慢恢复种群；过度捕猎会让附近动物长期减少。离线模拟设置上限，避免关闭游戏数日后种群爆满或全灭。

## 5. 驯养与繁殖

首批可驯养山羊、野兔和部分鸟类。驯养不是一次按钮操作，而是“投喂合适食物 → 保持安全距离 → 多次建立信任 → 引导进入围栏 → 提供食水和庇护”的长期过程。

- 山羊可产奶、剪取毛料并繁殖，需要草料、水和足够围栏空间。
- 野兔可繁殖并提供毛料或食物，需要隐蔽窝点，过度拥挤会停止繁殖。
- 部分鸟类可通过饲料和巢箱吸引，提供蛋与羽毛；迁徙水鸟不永久圈养。
- 海龟、蛇、野猪、果蝠和小型鲨鱼首版不驯养。

围栏必须参与碰撞与逃脱检查。缺水、缺食、恶劣环境和拥挤会降低健康与信任，但不会在玩家短暂离线时无提示集体死亡；离线负面结算有明确上限和回场提示。

## 6. 地表五层结构

### 6.1 基础地形层

沙滩、湿沙、泥地、草地、岩地、浅水和雪地使用多张无缝变化纹理。纹理通过种子噪声、坡度、含水量和生态区权重混合，不能出现方形区块接缝或大面积同纹理重复。

### 6.2 过渡层

- 海岸：浪线、泡沫、湿沙、潮痕和浅水深度。
- 林地：草地到泥土的踩踏过渡、根系和腐殖层。
- 红树林：积水、泥浆、裸露树根与漂浮落叶。
- 高地：裸岩、裂缝、碎石坡和风化边缘。
- 雨雪：积水、湿润边缘、薄雪和脚下扰动，不只叠加全屏滤镜。

### 6.3 微装饰层

草簇、落叶、枯枝、贝壳、小石、蘑菇、花、苔藓和浅水植物按地形确定性生成。微装饰不进入背包、不显示名称、不占用真实资源节点，也不与可采集资源使用相同尺寸、轮廓或高亮。

### 6.4 动态痕迹层

角色和动物可留下脚印、蹄印、泥水涟漪、压倒的草、血迹、羽毛、粪便、啃食痕迹和巢穴线索。雨会冲淡痕迹，雪地和湿泥保留更久。脚印与生态线索可被追踪系统和博物志任务读取。

### 6.5 实体层

资源、动物、角色和建筑按脚底坐标统一排序。树冠和高草可遮挡角色，但接近时会局部淡化；小型物品使用接触阴影、轻微摆动或反光提高可读性，不统一放大。真正可交互目标只显示最近或当前指向的名称和动作。

## 7. 数据与存档

共享内容新增：

- `animals.json`：属性、碰撞、速度、感知、行为、掉落、可驯养性和表现键。
- `habitats.json`：生物群系权重、昼夜窗口、天气条件、食物与水源依赖、种群容量。
- 动物相关物品、加工、陷阱、饲料、围栏、巢箱与畜牧配方。

世界存档新增动物实体、区域种群、巢穴、活动陷阱、驯养关系、围栏归属与需要保留的玩法痕迹。纯装饰的草、落叶和碎石由种子重建，不写入大型存档。旧存档迁移时按已发现区块初始化种群，不覆盖玩家建筑、资源节点与地形发现。

动物领域事件包括：发现、受惊、威吓、攻击、受伤、逃跑、捕获、死亡、处理产物、投喂、建立信任、驯养、繁殖和种群变化。任务、日记、动画、声音、掉落、存档和联机同步订阅这些事件。

## 8. 性能与跨端一致性

玩家附近动物使用完整行为和动画；远处区域只进行低频种群统计。活动半径、更新频率和寻路预算按性能档调整，但不删除动物种类、掉落、任务和碰撞规则。

- 流畅：减少约 65% 微装饰，关闭远处痕迹、草叶摆动和高成本反射，降低非关键动物动画频率。
- 均衡：保留主要地形过渡、附近动物痕迹和植被动态。
- 精细：完整草地响应、积水反射、风雨、较远痕迹与更高纹理等级。

动物生成、伤害、掉落和种群规则必须在所有平台一致。联机端允许客户端插值表现，但服务器拥有关键结果的最终决定权，使用事件 ID 防止重复掉落与重复繁殖。

## 9. 异常与安全降级

- 动物不会生成在建筑碰撞体、错误水深、不可达孤岛或玩家视野中心。
- 动物素材缺失时显示该动物专属剪影，并暂停其攻击与可捕获判定，避免不可见实体伤害玩家。
- 寻路失败时回退到归巢或原地警戒，不穿越水面、建筑或围栏。
- 服务器拒绝联机结算时回滚本地预测掉落，并显示可理解提示。
- 存档缺失个别动物状态时只重建对应种群，不重置完整世界。

## 10. 验收与测试

### 规则测试

- 十二种动物只在合法栖息地和活动时间生成。
- 多数动物先警戒和逃跑；危险动物仅在已定义触发条件下反击。
- 捕猎、陷阱、捕鱼、掉落和工具耐久形成完整消耗链。
- 过度捕猎降低种群；食物、水源和繁殖个体允许有限恢复。
- 驯养需要连续信任过程，围栏能阻挡且拥挤限制繁殖。
- 存档恢复、离线结算、联机重试不会重复动物和掉落。

### 视觉测试

- 桌面、常见手机和平板均保存实际运行截图，检查动物尺寸、脚底排序、遮挡、地表接缝、资源可读性和天气变化。
- 沙滩、林地、红树林、高地、浅水和雪地必须能够在无文字标签时辨认。
- 装饰物不会遮住任务目标或被误认为可采集物。

### 性能测试

- 低配档在相同玩法实体数下验证稳定帧率、内存峰值和动物更新预算。
- 活动区外不运行高频寻路；镜头缩小时不绘制全部微装饰和痕迹。
- Apple、Android、鸿蒙和 Web 分别验证后台恢复、长时间运行和存档大小。

## 11. 实施顺序

1. 建立共享动物、栖息地、种群、事件和存档迁移规则。
2. 在 Web 与 Android 接入可玩的动物移动、警戒、逃跑、反击、捕猎和掉落。
3. 完成地表五层、痕迹、动物与角色的统一深度排序及性能档。
4. 同步 Apple 原生端。
5. 同步鸿蒙单机版与联机版，并接入服务器关键结算。
6. 完成跨端回归、实际运行截图、版本提升、正式签名构建和下载中心发布。

每一步必须保持旧存档可迁移。正式构建前必须更新 `website/api/data/changelogs.json`、下载 manifest 与 client downloads；安装包放入 `website/api/apps` 后再验证下载中心实际可见和可下载。

## 12. 非目标

- 不把动物做成固定位置、不会移动的资源节点。
- 不把所有动物设计成主动敌人或无限刷新的战利品。
- 不用 SVG 线稿或同一张贴图替代全部动物状态。
- 不为每个平台复制不同玩法规则。
- 不用增加更多常驻 HUD 按钮代替世界内交互。
