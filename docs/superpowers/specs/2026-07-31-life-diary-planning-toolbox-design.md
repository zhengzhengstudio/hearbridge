# LifeDiary 可选生活工具箱设计规格

日期：2026-07-31  
状态：用户已确认产品设计，等待规格文件复核后进入实施计划

## 1. 目标

把生活日记从以记录为主的应用扩展为每天可使用的生活组织工具，同时保持原有边界：个人数据默认私密、社区分享必须显式创建公开副本、联机版本地优先同步、HarmonyOS 单机版完全离线、所有客户端使用平台原生界面而非 WebView。

本阶段覆盖 Web、Android、iOS、macOS、HarmonyOS 联机版与 HarmonyOS 单机版，并修复 LifeDiary 安装包被其他产品清单生成流程覆盖、线上下载中心仍显示旧版的问题。

## 2. 产品结构

采用“独立工具箱 + 今天聚合”结构。

- 工具保有适合自身行为的数据模型，不伪装成日记条目。
- “今天”聚合所有已开启工具的当前事项，但不展示未开启模块。
- 不新增第六个移动端底部标签；从“今天”进入“全部工具”。
- iPad、Android 大屏与 macOS 使用侧栏或分栏呈现工具箱。
- 工具入口允许开启、关闭和排序，关闭模块不会删除已有数据。

不采用“所有内容都写进日记”的设计，因为重复课程、任务状态和通知无法可靠表达；也不采用日历中心设计，避免产品退化为普通日历应用。

## 3. 首批工具

### 3.1 计划与待办

支持一次性任务、重复任务、长期目标、目标阶段、无日期的稍后清单、优先级、标签、子任务、备注、附件引用、拖动排序、完成记录和归档。

重复规则至少覆盖每日、每周指定工作日、每月指定日期与自定义间隔。重复任务完成时只完成当前实例，不销毁重复模板。

### 3.2 今日安排

今日安排聚合：

- 当前和下一项日程
- 今天到期或计划完成的任务
- 今天的课程、临时调课与考试
- 习惯打卡
- 最近倒数日
- 进行中的专注计时

用户可以调整模块顺序、折叠模块、隐藏已完成项目和设置每天开始时间。

### 3.3 课程表

课程表是所有用户都能按需开启的固定周安排，不依赖“学生”身份。

课程支持周一至周日、节次或具体起止时间、单双周、指定周、有效日期范围、教室、老师、颜色、备注、课前提醒、停课、补课和临时调课。课程可关联作业、考试和资料引用。

首版支持 CSV 与 ICS 导入导出，不连接学校教务系统，不收集教务账号密码，不实现图片识别导入。

### 3.4 作业与考试

作业只是关联课程的私密待办，不提供提交、教师端、批改、评分或班级收作业功能。

作业支持截止时间、优先级、备注、子任务、提醒和完成历史。考试支持科目、时间、地点、范围、备注和倒数提醒。

完成作业后可执行“写进今天的日记”。系统生成可编辑的私密日记草稿，只有用户再次确认保存后才进入个人日记。它不会自动发布到社区，也不会自动提供给陪伴助手。

### 3.5 习惯打卡

支持每日、每周次数和指定工作日三类频率，记录完成、跳过和备注。统计使用温和表述，不把中断描述为失败，不以红色惩罚或强制排名刺激用户。

### 3.6 倒数日

支持一次性日期、周年重复、置顶、颜色和提醒。只展示用户输入的标题和剩余时间。

### 3.7 番茄钟与专注计时

支持自定义专注/休息长度、暂停、提前结束、关联任务和本地专注记录。计时必须使用系统时间计算，不依赖页面持续运行。

### 3.8 购物与普通清单

支持多个清单、项目数量、备注、勾选、排序、隐藏已完成和本地归档。首版不加入多人协作。

记账、服药和喝水提醒不在首批范围内。

## 4. 数据模型与边界

各端共享语义一致的数据实体：

- `ToolPreference`：工具启用状态、顺序和首页显示偏好
- `Task`、`TaskRecurrence`、`TaskOccurrence`、`Subtask`
- `Goal`、`GoalMilestone`
- `ScheduleEvent`
- `Course`、`CourseOccurrenceOverride`
- `Homework`、`Exam`
- `Habit`、`HabitCheckIn`
- `Countdown`
- `FocusSession`
- `Checklist`、`ChecklistItem`

每个实体包含稳定 ID、创建/更新时间、逻辑删除状态和版本字段。联机版同步域使用 `planning`，服务端只接受该私密域，不允许社区接口直接引用私密实体 ID。单机版把相同语义的数据加入本地备份，但不包含任何同步状态或网络依赖。

## 5. 隐私、同步与社区

- 工具数据默认全部私密。
- 联机版绑定通行证后跨设备同步；离线时继续编辑并进入本地待同步队列。
- 单机版只保存在本机，并纳入用户主动导出的 JSON 备份。
- 工具数据不自动进入社区、聊天或陪伴助手。
- 陪伴助手只有在用户明确勾选具体项目后，才能帮助拆解计划或安排一天，并在回应中列出实际使用的项目。
- 若未来分享计划，只生成独立公开副本；首版不提供工具社区分享。
- 同一实体发生并发冲突时保留本地和远端版本，展示差异并让用户选择，不静默覆盖。

## 6. 通知与系统集成

首次启动不申请通知权限。用户第一次启用提醒时，应用先展示用途说明，再调用各平台系统权限请求。

通知支持到点、提前、稍后提醒、完成操作和静默时段。通知默认只显示事项标题和时间，不显示私密备注、附件、日记正文或健康内容。用户拒绝权限后所有工具仍可使用，应用内显示提醒状态和重新开启路径。

未成年人模式默认启用夜间静默。学习工具仍可正常使用，课程、作业和计划不会自动发送给监护人或其他账户。

系统日历集成采用显式授权和单向写入：用户逐项选择写入系统日历，LifeDiary 不自动读取或修改既有系统日历。首版不做双向同步。

## 7. HarmonyOS 服务卡片

HarmonyOS 联机版和单机版均提供原生服务卡片：

- 今天：进度与最近三项安排
- 下一节：课程名称、时间和地点
- 倒数日：最近的重要日期
- 快速打卡：完成习惯或任务
- 快速记录：打开原生日记编辑器

卡片仅显示用户允许的字段。锁屏、未解锁或隐私保护状态下隐藏地点、备注等细节。单机版卡片只读取本地数据库，不声明网络权限；联机版也不从卡片直接发起私密内容同步。

## 8. 各端界面原则

- Web：今天页增加可排序聚合区和独立工具箱页面。
- Android：Compose 原生页面，手机使用“今天”内工具入口，大屏使用 NavigationRail/分栏。
- iOS：SwiftUI 原生页面，遵循 NavigationStack、系统通知和日历权限模式。
- macOS：侧栏增加“工具箱”组，支持键盘新建、搜索和多窗口一致性。
- HarmonyOS：ArkUI 原生工具页和服务卡片；联机/单机共享语义，不共享网络实现。
- 所有端继续使用现有 LifeDiary 设计令牌、动态字体、深色模式和隐私遮挡。
- 不添加 WebView、ArkWeb、内嵌浏览器页面或网站壳。

## 9. 下载中心修复

当前线上下载中心能返回 LifeDiary 条目，但仍是 0.1.0；本地曾提交的 0.2.0 清单被后续 SpaceFight 清单生成流程覆盖。

修复要求：

- 恢复 LifeDiary 0.2.0 的 Web、Android、iOS、macOS、HarmonyOS 联机 HAP/APP、HarmonyOS 单机 HAP/APP 条目。
- 下载页明确显示平台、联机/单机、版本/build、签名和商店就绪状态。
- 所有产品发布脚本通过应用 ID 合并清单，不整体替换其他产品条目。
- `manifest.json` 与 `client-downloads.json` 的 API 和公开镜像必须保持一致。
- 生成流程结束后验证文件存在、大小和 SHA-256；缺失文件不得生成可下载卡片。
- 增加顺序无关测试：先发布 LifeDiary 再发布 SpaceFight，以及反向顺序，两个产品都必须保留。

## 10. 错误处理

- 本地持久化失败时不声称已保存或完成。
- 通知调度失败时保留事项并显示可恢复状态。
- 导入操作先完整验证再原子提交；未知字段保留兼容，非法记录单独报告。
- 同步失败不阻塞本地编辑；只有服务端明确确认后才移除待同步操作。
- 课程重复展开、时区和夏令时计算使用当地日历语义，原始起止时间和时区同时保存。
- 服务卡片数据不可用时显示中性空状态，不展示过期的敏感内容。

## 11. 测试与验收

### 11.1 模型测试

- 重复任务展开与单实例完成
- 单双周、指定周、跨学期与临时调课
- 跨日安排、时区变化和夏令时
- 作业写入日记必须经过草稿与二次确认
- 习惯中断不删除历史
- 专注计时在进程暂停后仍按系统时间恢复

### 11.2 隐私与平台测试

- 通知权限只在用户启用提醒后申请
- 拒绝通知权限不影响保存
- 通知不包含备注、日记或健康正文
- 陪伴助手只接收用户勾选的项目
- 单机版运行源码和包不包含联网权限或在线服务
- HarmonyOS 卡片在隐私状态隐藏详细信息
- 所有端继续保持零 WebView/ArkWeb

### 11.3 同步与发布测试

- 同步冲突保留两个版本
- 重试操作幂等，不重复创建任务或课程
- 数据导出包含所有已启用工具
- CSV/ICS 导入失败不污染已有数据
- LifeDiary 与其他产品的清单生成顺序不影响最终条目集合
- 下载中心 LifeDiary 卡片的版本、build、签名状态、文件大小和 SHA-256 与包一致

## 12. 实施顺序

1. 先修复下载中心清单合并，恢复可下载的 0.2.0 条目。
2. 建立跨端共享语义、服务端 `planning` 私密域和测试夹具。
3. 实现 Web 与核心模型契约，作为各端行为参考。
4. 实现 Android、iOS、macOS 原生工具箱与通知。
5. 实现 HarmonyOS 联机版、单机版及服务卡片。
6. 完成跨端回归、真实构建、版本提升、包发布和更新日志。

## 13. 明确排除

- 作业提交、教师端、批改、评分、班级管理
- 教务系统账号登录或抓取
- 自动图片识别课程表
- 多人协作清单
- 记账、服药、喝水提醒
- 系统日历双向同步
- 工具内容自动发布社区或自动提供给陪伴助手
