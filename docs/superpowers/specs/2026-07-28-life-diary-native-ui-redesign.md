# 生活日记全端原生 UI 与 App Icon 重设计规格

日期：2026-07-28

状态：已完成对话设计确认，等待书面规格复核

产品：生活日记（LifeDiary）

## 1. 改造目标

本次改造保留已经可用的网页版与 LifeDiary API，但彻底移除 Android、iOS、macOS 和 HarmonyOS 联机版主界面中的 WebView。所有 App 页面改为各平台原生实现，并重新生成一套独立的 App Icon，不复用网页截图、旧图标碎片或合成式界面元素。

HarmonyOS 单机版继续保持无账户、无联网权限的产品边界，同时重做其 ArkUI 界面。网站仍可通过明确的“打开网页版”操作交给系统浏览器访问；铮铮通行证使用系统授权页；业务数据继续通过现有 LifeDiary API 交换。

本次不改变已确认的产品功能与隐私边界，不接入尚未完成的“生存日记”游戏。

## 2. 当前问题与改造边界

### 2.1 当前问题

- Android、iOS、macOS 与 HarmonyOS 联机版主要以网页容器承载功能，平台导航只是外层包装。
- HarmonyOS 单机版已经使用 ArkUI，但页面集中、信息层级粗，尚未形成完整原生产品体验。
- 现有 App Icon 来自旧 SVG、前景图和背景图的复用或组合，缺少独立生成的品牌母版。
- Android 的 LifeDiary 工程中混入 SurvivalDiary flavor，增加了品牌、资源和发布配置串用的风险。

### 2.2 本次包含

- 全新独立 App Icon 母版和各平台适配资源。
- iOS、Android、macOS、HarmonyOS 联机版全部主功能原生化。
- HarmonyOS 单机版原生 UI 重构。
- 通行证系统授权、现有 API、本地优先存储、同步、更新与平台系统能力接入。
- 原生界面的空数据、加载、离线、错误、授权过期、同步冲突和删除确认状态。
- 各端构建、契约测试、关键界面测试与可访问性检查。

### 2.3 本次不包含

- 重做网页版。
- 修改现有社区、好友、陪伴助手和健康数据的服务端业务语义。
- 将 HarmonyOS 单机版改为联网产品。
- 将各平台强行做成像素级一致的跨平台皮肤。

## 3. 设计方向：纸页与苔痕 2.0

品牌保留暖米白、苔绿色与纸张般安静的气质，但升级为更克制、更系统原生的“纸页与苔痕 2.0”。

- 主色：深苔绿，用于主操作、选中状态与品牌识别。
- 基底：暖象牙白，用于内容背景和轻量表面。
- 辅色：灰鼠尾草，用于次级状态、图表和非关键强调。
- 文字：炭墨色，保证正文对比度和长时间阅读舒适度。
- 深色模式：带绿色倾向的炭黑与低亮度鼠尾草，不使用简单颜色反相。
- 纹理：只允许出现在大面积空白背景或品牌插图中，不覆盖正文、表单和数据。
- 装饰：以连续书写轨迹、页角和柔和几何弧线为核心，避免大量悬浮卡片、玻璃拟态和无意义渐变。
- 性别表达：不使用粉色代表经期、蓝色代表戒烟；两个工具共用同一视觉体系。

品牌一致性只覆盖图标、颜色、内容语气、间距节奏和插图母题。导航、控件、弹窗、文件选择、返回行为和系统反馈必须遵循各平台规范。

## 4. App Icon

### 4.1 核心意象

图标采用“展开的日记本＋一笔连续书写轨迹”。轨迹从左页进入右页，既像正在书写的一笔，也像一天向下一天延续。图标不包含产品文字、字母、日期数字、人物、设备或网页界面。

### 4.2 生成要求

- 使用图像生成工具创建独立母版，不拼接现有资产。
- 构图必须在小尺寸下仍能辨认：一个主轮廓、一个连续轨迹、有限层次。
- 使用暖象牙白纸页、深苔绿封面或底色、灰鼠尾草细节。
- 不使用写实纸张阴影、复杂纹理、细小文字、透明边缘水印或第三方品牌。
- 先生成无圆角的 1024×1024 母版；圆角与遮罩交给平台处理。

### 4.3 平台输出

- iOS：1024×1024 App Store 母版，不预裁圆角，不使用透明通道；生成完整 AppIcon 资源集。
- Android：Adaptive Icon，独立输出背景层与安全区内的前景层，同时提供单色图标用于主题图标；不把整张方形图塞进前景层。
- macOS：保留更充足的外围留白和轻微体积层次，生成完整 `.icns` 所需尺寸。
- HarmonyOS：生成前景、背景与分层资源，主体保持在系统安全区内，联机版与单机版共用母题但通过名称和包标识区分，不在图标上写 `online` 或 `offline`。

## 5. 全端信息架构

### 5.1 手机与鸿蒙设备

联机版主导航为五个原生入口：

1. **今天**：自然问候、一句话快记、心情与难受程度、近期回望。统计数据不得抢占首屏中心。
2. **日记**：时间流与日历切换、搜索、标签、时光胶囊、编辑、导出和隐私遮挡。
3. **连接**：社区、好友和聊天。社区发布始终创建公开副本，不直接公开个人原文。
4. **陪伴**：明确标注 AI 身份，提供倾听、鼓励和建议三种风格，并展示本次获授权的数据来源。
5. **我的**：健康记录、应用锁、未成年人模式、导出、同步状态、更新、网页版入口与通行证。

HarmonyOS 单机版保留四个入口：今天、日记、健康、我的。它不显示连接、在线陪伴、通行证或同步入口。

### 5.2 macOS

macOS 使用 `NavigationSplitView`，而不是放大手机底栏：

- 记录：今天、个人日记、健康记录。
- 连接：社区、好友、消息。
- 陪伴：对话、每周回望、记忆管理。
- 资料与设置：通行证、隐私、备份、未成年人模式、更新与网页版入口。

侧栏只保留图标、标题和必要的未读数；内容列表位于中间栏；编辑、详情或来源信息位于详情栏或检查器。核心操作同时提供工具栏、菜单和键盘快捷键。搜索使用系统工具栏，支持多窗口、拖放导出和标准设置窗口。

## 6. 平台实现要求

### 6.1 iOS 16+

- 使用 SwiftUI、`TabView`、每个标签独立的 `NavigationStack`、原生 Sheet、菜单和系统分享。
- 使用动态字体、VoiceOver 标签、Reduce Motion、深色模式和安全区。
- 使用 Keychain 保存通行证令牌，使用 LocalAuthentication 接入 Face ID/Touch ID 应用锁。
- 使用系统浏览器授权会话完成通行证登录，通过 Universal Link 返回 App。
- 使用系统文件选择器完成导入导出；版本更新只进入系统允许的商店或安装入口。

### 6.2 Android 8.0+ / API 26+

- 将 LifeDiary 工程改为专用产品工程，移除 SurvivalDiary flavor 和网页资产同步任务；不修改独立的 SurvivalDiary 工程或产品。
- 使用 Kotlin、Jetpack Compose 与 Material 3；采用 Navigation Compose、适应窗口宽度的底栏或导航轨道。
- 遵循系统返回、预测性返回、动态字体、TalkBack、边到边布局和系统深色模式。
- 使用 Android Keystore、BiometricPrompt、Credential/浏览器授权流程与系统文件选择器。
- 更新包下载至系统 Downloads，校验大小与 SHA-256 后调用系统安装器；失败时删除损坏文件并显示可恢复状态。

### 6.3 macOS 13+

- 使用 SwiftUI `NavigationSplitView`、`Settings`、Commands、工具栏、`searchable` 和系统材料。
- 支持键盘与指针操作，不使用触屏式全屏分页作为主要交互。
- 通行证由系统浏览器授权并通过 URL Scheme/Universal Link 回调。
- 使用 Keychain 和本机生物识别能力保护敏感数据；更新下载到 Downloads，校验后打开系统安装流程。

### 6.4 HarmonyOS 6.0+

- 联机版和单机版均使用 ArkUI 原生页面、Navigation 与 Tabs，并适配 phone、tablet 和 2in1 布局。
- 联机版接入 Account Kit、系统分享、碰一碰好友申请、API 同步和更新检查。
- 单机版不声明 INTERNET 权限，不包含通行证、云同步、社区、好友、聊天或在线助手代码路径。
- 双版本读取系统未成年人状态，但只在注册、登录或本机年龄设置完成后提示，不自动开启模式。
- 碰一碰仅交换短时一次性令牌，接收方确认后才发送好友申请；不交换设备名称和个人内容。

## 7. 原生页面设计

### 7.1 今天

顶部使用系统导航标题和一句随时间变化的问候。主要区域只有一个清晰的“一句话快记”入口，随后是可选的心情、难受程度与标签。近期回望使用时间线或原生列表，不使用仪表盘式卡片墙。

### 7.2 个人日记

日历与时间流是两种视图状态。编辑器使用平台原生文本编辑、图片选择、标签菜单和保存反馈。敏感内容可模糊；应用切换器和通知不得泄露正文。时光胶囊在打开日期前只显示日期和用户自定义标题。

### 7.3 健康记录

经期与戒烟由用户主动开启。经期预测展示日期范围、历史样本数和可信程度；戒烟记录重点展示当前烟瘾应对和连续时间，不设置排行榜或羞辱性文案。严重疼痛与危机内容只提供克制的求助建议，不进行诊断。

### 7.4 连接

社区使用明显不同于私人日记的顶栏和发布确认提示。发布前显示最终公开副本，并明确“这将出现在社区”。好友申请、聊天、拉黑和举报使用平台标准列表、菜单与确认流程，不展示设备名称。

### 7.5 陪伴

对话顶部持续显示“AI 陪伴助手”。发送前可选择回复风格与授权的日记条目；回答后可查看来源。长期记忆先生成草稿，由用户确认后保存；记忆可以逐条删除或全部清空。

### 7.6 我的与设置

设置按账户、隐私、健康工具、未成年人模式、数据、通知和关于分组。应用锁、导出和彻底删除位于隐私与数据区；检查更新和打开网页版位于关于区。危险操作使用系统确认弹窗，不做自定义伪弹窗。

## 8. 登录、数据与同步

- 联机版首次使用先显示简短欢迎页，再通过系统浏览器打开铮铮通行证；授权完成后通过平台深链返回。
- 日记、健康记录和草稿先保存到本机加密存储，再进入同步队列调用现有 LifeDiary API。
- 断网、登录过期、服务器异常或同步失败不得阻止本地记录。
- 同步继续使用修订号；冲突时保留本机和远端两个版本，由用户选择、合并或复制。
- 社区、好友、聊天和在线陪伴仅在联网且授权有效时使用；离线时展示真实状态与重试入口。
- 网站链接使用系统外部浏览器；除通行证授权会话外，App 内不嵌入网页。

## 9. 未成年人模式与隐私

- 提示仅在未成年人注册、登录或单机版本机年龄设置完成后触发。
- 提供开启、稍后、7 天内不再提示和永久不再提示；设置中可以恢复。
- HarmonyOS 双版本可以读取系统未成年人状态，但不能据此未经确认自动开启模式。
- 未成年人模式限制陌生人主动联系、位置展示和外发内容，并增加社区发布与好友申请二次确认。
- 通知只显示中性提醒，不包含日记正文、健康详情、烟瘾记录或助手敏感回复。
- 单机版年龄状态、日记和健康内容不得上传。

## 10. 更新、错误与恢复状态

- 联机客户端比较清单中的语义版本与 build；远端更高时显示平台原生更新提示。
- Android、macOS 与 HarmonyOS 联机版按平台规则下载、校验和调用系统安装入口；iOS 使用系统允许的商店或安装入口；HarmonyOS 单机版由应用市场更新。
- 所有页面必须提供加载、空数据、离线、授权过期、同步冲突、权限拒绝、删除确认和重试状态。
- 网络写操作使用去重键与退避重试，避免重复发布、重复好友申请和重复消息。
- 本地保存成功但同步失败时，界面必须明确区分“已保存在本机”和“尚未同步”。

## 11. 代码边界

每个平台将界面、模型、存储、API、认证、同步、更新和平台能力拆为独立模块。页面不得直接拼接 API 请求或访问全局单例。

- Views/Screens：纯界面与局部交互状态。
- Models：日记、健康、社区、好友、消息、助手和同步状态值类型。
- Stores：本机持久化、加密与同步队列。
- Services：通行证、LifeDiary API、更新、文件导入导出和平台能力。
- Navigation：每个平台独立的路由与深链映射。
- DesignSystem：跨页面共用的品牌色、间距、图标语义与可访问性规则，但使用平台原生组件实现。

iOS 与 macOS 保持多文件 SwiftUI 结构；Android 使用 Kotlin/Compose feature 包；HarmonyOS 按 pages、components、models、stores 与 services 拆分，禁止继续把全部页面堆入单个 `Index.ets`。

## 12. 测试与验收

### 12.1 测试策略

- 先为原生导航、数据模型、同步冲突、更新判断和隐私边界编写失败测试，再实现功能。
- iOS/macOS：Swift 测试覆盖模型、路由和服务；构建覆盖 iOS 设备目标与 macOS Release。
- Android：JVM 单元测试、Compose UI 测试、lint 和 Release 构建。
- HarmonyOS：ArkTS 单元测试、页面契约测试、HAP/APP Release 构建。
- 现有 LifeDiary Web/API 测试必须继续通过。

### 12.2 视觉验收

- App Icon 为独立生成资产，不包含旧 SVG 拼接痕迹或界面截图。
- 五端共享“纸页与苔痕 2.0”品牌，但导航、控件和反馈符合各平台惯例。
- App 主流程不存在 WebView 或内嵌站点。
- 动态字体、深色模式、屏幕阅读器、键盘焦点和减少动态效果可用。
- 手机、平板、2in1 与 macOS 常见窗口宽度无横向溢出或被遮挡操作。

### 12.3 功能验收

- 通行证授权能通过系统浏览器返回 App，令牌安全保存。
- 断网时能创建和编辑日记；恢复联网后可以同步。
- 经期与戒烟工具由用户主动开启，不受性别字段限制。
- 私人日记无法被一个开关直接公开；社区发布创建副本并再次确认。
- 陪伴助手未获授权时不能读取日记，获授权后显示来源。
- 未成年人提示时机和四种选择正确，设置中可以恢复。
- HarmonyOS 单机版无联网权限和在线代码路径。
- 更新包匹配正确平台与变体，并按签名状态诚实展示。

## 13. 发布要求

完成原生重构后统一提升版本与 build，重新构建各平台包，更新 `website/api/apps/manifest.json`、`client-downloads.json`、下载中心简介与 SHA-256，并按网站规则更新 `website/api/data/changelogs.json`。

只有经过对应平台正式证书验证的构建才能标为 `signed` 或 `storeReady`。缺少 Android 正式上传密钥、Apple Distribution/Developer ID、Apple 公证凭据或 HarmonyOS 对应包名 Release Profile 时，构建结果必须明确标为测试签名或未签名，不能伪装为正式上架包。
