# 铮铮音乐工作室双工作区设计

## 目标

把现有七个平级工具页面重组为一个面向音乐学生的真实应用。一级导航只保留“创作”和“学习”，所有现有能力都进入这两条连续工作流，不再以功能卡片形式散落。

## 方案选择

采用同一 App 壳内的双工作区方案：

- 不采用单页堆叠：创作和训练任务差异太大，会继续造成信息拥挤。
- 不拆成两个独立网站：账号、作品、播放器和音乐数据需要共享。
- 采用双工作区：桌面使用左侧窄导航，手机使用底部双入口；全局工程名、账号和播放器保持一致。

## 创作页

创作页是工程工作台，按创作顺序组织：

1. 顶部工程栏显示作品名、保存状态、通行证账号和导出菜单。
2. 左侧创作抽屉包含文本、哼唱、纯音乐、歌曲四种输入模式，以及风格、情绪、速度和时长。
3. 中央编辑区以段落时间线为核心，显示 Intro、Verse、Chorus 等结构，并提供旋律、和弦、低音、鼓组四条轨道。
4. 编辑区可在“轨道”和“谱面”之间切换；现有音序器、和弦条和 VexFlow 谱面继续复用。
5. 底部播放器始终可见，支持播放、暂停、停止、进度与分轨开关。
6. 我的作品变为工程侧栏，不再占用一级导航；选择作品后载入当前工程。

生成完成后保持在同一工程内，直接播放并允许变奏、改音符、保存和导出，不跳到结果卡片。

## 学习页

学习页使用四个二级标签：

- 构唱：生成练习、播放参考音、显示唱名。
- 识谱：五线谱题目、答案选择和即时反馈。
- 音程：播放音程、作答、显示正确结果。
- 资料库：显示可用训练样本、许可来源和导入规则。

学习页顶部显示当天练习进度；各训练模块共享声音设置，但不占用创作工程的编辑空间。

## 响应式与视觉

- 使用深灰工作台底色、暖白文字和低饱和薄荷绿作为唯一主强调色，不使用紫蓝渐变或“AI”装饰。
- 桌面是紧凑制作台；平板将创作抽屉折叠；手机只显示当前任务，并保留底部双入口与迷你播放器。
- 控件使用明确图标、工具提示、焦点状态、加载状态和空状态。
- 页面不再出现大标题营销布局、嵌套卡片或字母占位图标。

## 状态与数据流

- 保留现有通行证、访客本地作品、云端历史、生成 API、训练库 API 和导出逻辑。
- 新增当前工程 UI 状态：当前主工作区、学习标签、编辑器标签、作品侧栏和创作抽屉开关。
- 生成、载入作品和手动编辑都写入同一 `state`，然后统一刷新时间线、轨道、谱面和播放器。
- API 失败时保留本地可编辑工程，并在工程栏显示可重试状态，不使用弹窗阻断。

## 验收

- 首屏只能看到“创作”和“学习”两个一级入口。
- 新用户可在创作页完成描述、生成、站内试听、编辑、保存和导出。
- 学习页四项能力均能独立使用，并可回到创作工程而不丢失状态。
- 390px 手机和 1280px 桌面无内容重叠、页面级横向滚动或被播放器遮挡的最终内容。
- 页面加载、主导航、生成、播放、编辑器切换和学习标签切换无相关控制台错误。
