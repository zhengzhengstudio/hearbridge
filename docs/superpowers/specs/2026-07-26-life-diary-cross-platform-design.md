# 生活日记全端产品设计规格

日期：2026-07-26
状态：已完成对话确认，等待书面规格复核
产品名称：生活日记（LifeDiary）

## 1. 目标与范围

生活日记是一款面向全年龄用户的私密生活记录与温和陪伴产品。它同时提供个人日记、健康记录、社区分享、陪伴助手和好友聊天，但这些数据域必须彼此隔离，用户不会因为记录个人生活而意外公开内容。

首版覆盖：

- Web：`life.zhengzhengstudio.cn`
- Android
- iOS
- macOS
- HarmonyOS 联机版
- HarmonyOS 单机版（用于鸿蒙应用市场）

首版不接入尚未完成的“生存日记”游戏，也不显示不可用入口。只预留未来经过用户授权后使用的稳定数据接口。

## 2. 已确认的产品原则

1. 经期记录和戒烟日记由用户主动开启，不按性别自动分配。性别可以作为自愿填写的档案字段，但不决定功能资格。
2. 个人日记与社区分享是两个独立入口、独立数据对象。个人记录不会自动公开。
3. 社区存在，但首版不支持匿名发布。社区只展示通行证昵称和头像，不公开真实 UID。
4. 产品面向全年龄。未成年人注册或登录时提示未成年人模式，但不自动开启；用户可选择开启、稍后再说、7 天内不再提示或永久不再提示。永久不提示后仍可在设置中主动开启。
5. HarmonyOS 联机版和单机版都适配系统未成年人模式。系统状态用于调整提示和功能，不上传单机版状态，也不未经用户确认直接开启模式。
6. Web、Android、iOS、macOS 和 HarmonyOS 联机版首次使用必须绑定铮铮通行证。HarmonyOS 单机版免登录且不包含通行证能力。
7. 好友关系和一对一聊天在所有联机端同步可用。HarmonyOS 联机版额外支持碰一碰发送一次性好友申请。
8. “实物图”采用真实 App 截图和无品牌、无设备型号的通用设备场景效果图。效果图不得宣称为真实拍摄。

## 3. 产品结构

### 3.1 今天

- 一句话快记：以最低操作成本记录此刻，之后可补成完整日记。
- 快速记录心情、生活事件、今日难受程度和自定义标签。
- 展示近期回顾、温和提醒和连续记录，不以断签或失败责备用户。
- 所有人都可记录身体不适、压力、孤独、疲惫等状态，不把“痛苦”限定于某种性别或健康模块。

### 3.2 个人日记

- 支持文字、图片、心情和自定义标签。
- 支持日历、时间流、搜索、筛选、编辑、导出和删除。
- 敏感图片和正文可遮挡；应用切换器、通知和桌面预览不显示敏感正文。
- 支持时光胶囊：内容到指定日期才重新出现。
- 支持普通一天、开心的事、睡不着、争吵之后、烟瘾来临、经期不适等模板。

### 3.3 健康记录

#### 经期记录

- 记录开始与结束日期、流量、疼痛 0–10、症状和备注。
- 根据历史周期给出下次日期范围与可信程度，不使用伪精确的单日结论。
- 历史不足时明确说明无法可靠预测。
- 对明显异常或严重疼痛只给出关注和寻求专业帮助的建议，不进行诊断。

#### 戒烟日记

- 记录戒烟开始时间、原每日数量、单价、烟瘾强度、诱因和是否复吸。
- 计算无烟时长、少吸数量和节省金额。
- 重点帮助用户度过当前烟瘾，不设置公开排行榜，不使用羞辱或责备式文案。

### 3.4 社区

- 社区发布必须创建新副本；不能通过一个“公开”开关把个人日记原件直接暴露。
- 支持话题流、发布、点赞、评论、关注、举报和拉黑。
- 首版话题可包含“今天也很累”“戒烟互助”“经期照护”“生活里的小确幸”等。
- 不支持匿名发布。后台保留真实通行证 UID 供审核、封禁和申诉使用。
- 健康记录、陪伴助手记忆和未成年人模式状态永不自动进入社区。

### 3.5 陪伴助手

- 提供倾听、回顾、提醒和生活建议，不冒充真人，不替代医疗服务。
- 用户可选择安静倾听、温柔鼓励或直接建议三种回复风格。
- 默认只使用当前对话；读取日记需要明确授权，长期记忆需要单独开启。
- 用户可查看本次回答使用了哪些日记、查看和删除单条记忆，并可一键清空。
- 每周回望由助手生成草稿，只有用户确认后才保存。
- 遇到自伤、严重疼痛等危机内容时提供克制、明确的求助提示。

### 3.6 好友与聊天

- 全联机端支持搜索用户、查看社区主页、发送/接受/拒绝好友申请、删除好友、拉黑、举报和一对一聊天。
- HarmonyOS 联机版支持碰一碰发送好友申请：设备之间只交换短时、一次性邀请令牌，不交换手机号、密码、健康数据或日记正文。
- 碰一碰后必须由接收方确认，服务器才建立好友关系。
- HarmonyOS 单机版不提供好友、聊天或碰一碰。

### 3.7 隐私保险箱与关怀联系人

- 支持应用锁、敏感内容遮挡、数据导出、备份和彻底删除。
- 用户可主动设置可信关怀联系人，但系统不会自动把日记或健康数据发送给对方。
- 未成年人模式默认关闭陌生人主动联系和位置展示，并对社区发布、好友申请和外发内容增加二次确认。
- 监护人不能直接读取日记正文，除非用户主动分享。

## 4. 技术架构

采用“共享产品核心 + 各端原生能力桥接”的路线。

### 4.1 Web 与共享核心

- 沿用现有网站的原生 HTML、CSS、JavaScript 技术路线，建设响应式生活日记站点。
- 共享业务层负责日记模型、健康计算、同步队列、社区、助手和聊天协议。
- 联机端优先写入本机加密存储，登录后异步同步；断网不影响记录。

### 4.2 Android、iOS 与 macOS

- 使用内置前端资源保证核心体验一致，不依赖每次启动在线加载网站。
- 原生桥接负责安全存储、应用锁、通知、文件导出、下载目录、系统分享、深链和版本安装入口。
- 平台导航、返回、分享、文件权限和安装流程遵循各系统习惯。

### 4.3 HarmonyOS

- 联机版与单机版使用 ArkUI 适配系统能力与应用市场要求。
- 联机版接入通行证、同步、社区、好友、聊天、陪伴助手、更新检查和碰一碰。
- 单机版只保留本地日记、健康记录、本地规则陪伴、导出、应用锁和系统应用市场更新；不得包含联网权限、通行证、云同步、在线助手、社区或聊天接口。
- 两个版本均适配系统未成年人模式。

### 4.4 服务端边界

- 在现有 Node.js 服务中建立独立的 LifeDiary 路由、存储和测试模块，不把新业务继续堆入现有大型服务器文件。
- 个人日记、健康记录、助手记忆、社区帖子、好友关系和聊天使用独立存储边界与权限校验。
- 初期可以延续 JSON 存储模式，但接口和存储层必须解耦，为后续数据库迁移保留边界。
- 所有联机写操作使用通行证令牌识别用户，客户端提交的 UID 不作为授权依据。

## 5. 数据流与冲突处理

1. 用户输入先保存到本机并进入同步队列。
2. 联机后携带通行证授权同步到相应数据域。
3. 多设备编辑同一对象时使用修订号检测冲突；发生冲突保留两个版本，由用户选择或合并，不静默覆盖。
4. 发布社区内容时从用户选中的内容创建社区副本，并在发布前再次展示将要公开的最终内容。
5. 删除个人数据提供短期撤销；“立即彻底删除”再次确认，并删除云端副本、关联附件和获授权的助手记忆。
6. 社区副本与个人原文生命周期独立。删除个人原文不会静默删除社区帖子，删除社区帖子也不会影响个人原文。

## 6. 视觉与交互规则

实施 UI 时必须使用 `taste-skill` 的现有项目升级与高级界面规则，并在写 UI 代码前完成其要求的设计预检。

- 气质：温暖、安静、像纸张和晨光，不做粉色代表女性、蓝色代表男性的刻板区分。
- 色彩：低饱和苔绿色配暖米白；深色模式使用带绿色调的炭黑；全产品只保留一个主强调色。
- 字体：不使用 Inter；从 taste-skill 允许的字体栈中按设计预检结果选择。
- 首页：大面积留白和自然问候开场，首要操作是“一句话快记”，统计数据不占据首屏中心。
- 日记：日历与时间流结合，内容层级清楚，正文保持合适阅读宽度。
- 经期：使用日期范围和可信程度，不制造确定性。
- 戒烟：突出此刻如何度过烟瘾，累计数字只作温和鼓励。
- 社区：与私密日记形成明显视觉边界，发布前明确显示“这将出现在社区”。
- 助手：清楚标明 AI 身份和上下文来源，提供暂停记忆入口。
- 未成年人模式：语言正常、尊重，不采用幼儿化图案。
- 所有可点击组件提供悬停、按下、键盘焦点、加载、空数据和错误状态。
- Web 避免横向溢出，尊重系统减少动态效果设置。

## 7. 版本升级与发布

首发版本统一为 `0.1.0`、build `1`。所有清单和包内版本必须一致。

### 7.1 包名

- Web / Android：`cn.zhengzhengstudio.lifediary`
- iOS：`cn.zhengzhengstudio.lifediary.ios`
- macOS：`cn.zhengzhengstudio.lifediary.macos`
- HarmonyOS 联机版：`cn.zhengzhengstudio.lifediary.hmos`
- HarmonyOS 单机版：`cn.zhengzhengstudio.lifediary.offline.hmos`

### 7.2 更新规则

- 客户端读取 `website/api/apps/manifest.json` 中与自身产品、平台和变体完全匹配的条目。
- 远端语义版本更高，或版本相同但 build 更高时提示更新。
- 下载后校验文件大小和 SHA-256；校验失败时删除损坏副本并禁止安装。
- Android 和 macOS 下载到系统 Downloads 后调用系统安装入口。HarmonyOS 联机版在系统允许侧载安装时调用系统安装入口；系统不允许时保留已校验文件并打开 Downloads，明确提示用户完成安装。
- iOS 只使用系统允许的安装清单或商店分发入口，不承诺静默安装。
- HarmonyOS 单机版不访问站内更新清单，由鸿蒙应用市场负责更新。

### 7.3 构建与下载中心

- 正式包放入 `website/api/apps` 及现有下载路由所要求的镜像位置。
- 同步更新 `manifest.json`、`client-downloads.json`、版本号、build、简介、系统要求、文件大小和 SHA-256。
- 只把经过签名验证的包标记为 signed/storeReady。缺少证书、描述文件或签名口令时必须明确阻塞，不能把未签名包伪装为正式包。
- 网站下载中心必须显示 Web、Android、iOS、macOS、HarmonyOS 联机版和 HarmonyOS 单机版的清晰差异。

## 8. Cloudflare 与站点

- 配置 `life.zhengzhengstudio.cn` 的 Cloudflare DNS。
- DNS 目标沿用现有站点部署结构，配置前先读取现有区域记录，避免覆盖无关记录。
- 上线验收必须覆盖 HTTPS、静态资源、通行证回调、API、WebSocket/聊天和应用下载地址。

## 9. 鸿蒙应用市场素材

- 输出应用图标、真实界面截图、无品牌设备场景效果图、短描述、完整描述、功能卖点、隐私说明和版本说明。
- 场景效果图不出现设备品牌或型号，不标为真实拍摄。
- 单机版文案明确说明数据只保存在设备、不需要账号、不含社区和在线助手。
- 不使用医疗诊断、治疗效果或保证戒烟成功等无法证明的表述。

## 10. 异常与安全处理

- 登录、同步、社区、聊天和助手失败时仍必须保住本机日记。
- 网络重试使用退避和去重，避免重复发布、重复好友请求或重复消息。
- 社区和聊天提供举报、拉黑、限流、内容处理与未成年人保护状态。
- 碰一碰令牌短时有效、一次性使用、与发起用户和目标动作绑定。
- 通知不显示日记正文、健康详情或助手敏感回复。
- 导出默认生成用户可理解的结构化文件，并在导出前提示其中可能包含敏感信息。

## 11. 更新日志补齐

本次网站变更必须更新 `website/api/data/changelogs.json`。

“以往没更新到”的补齐采用证据驱动审计：对照 website 独立 Git 历史、现有构建产物、`manifest.json`、`client-downloads.json` 和已有发布文档，识别已经落地但缺少公开日志的变更。无法由代码、发布包或文档确认的历史内容不虚构。日志不包含管理员、高危漏洞修复、后端敏感细节等不应公开的信息。

## 12. 验收标准

### 功能

- 通行证注册/登录、未成年人提示四种选择和设置入口均可用。
- 个人日记离线新增、编辑、搜索、导出、删除和冲突恢复可用。
- 经期预测在历史不足和历史充足时给出不同、诚实的结果。
- 戒烟时长、少吸数量和节省金额计算正确，复吸记录不清零历史。
- 社区发布无法直接暴露个人原文，且点赞、评论、关注、举报和拉黑可用。
- 助手在未授权时无法读取日记，授权后可显示使用来源并可清除记忆。
- 好友申请、一对一聊天、删除、拉黑和消息去重可用。
- HarmonyOS 碰一碰令牌的一次性、过期和确认流程可验证。

### 隐私与变体

- HarmonyOS 单机版没有联网权限、在线域名、通行证、社区、聊天、在线助手或站内更新代码。
- 未成年人模式下陌生人联系、位置、社区发布和外发内容符合限制。
- 通知、任务切换器和系统预览不泄露敏感正文。

### 发布

- 全部包内版本、清单版本、build、文件名、大小和 SHA-256 一致。
- Android APK、Apple 安装包、HarmonyOS HAP/APP 的签名状态经过工具验证。
- 更新只匹配正确平台与变体，损坏包无法安装。
- 下载中心显示正确简介与下载入口。
- `changelogs.json` 包含本次公开变更及证据可确认的遗漏历史。
- `life.zhengzhengstudio.cn` 的 HTTPS、API、聊天和下载路径通过上线检查。

## 13. 实施分期

由于本项目包含多个独立子系统，实施按下列顺序推进，每一阶段都保留可运行状态：

1. Web 产品核心、通行证、个人日记和本地优先数据层。
2. 健康模块、隐私保险箱、未成年人模式和陪伴助手。
3. 社区、好友关系、一对一聊天和内容安全。
4. Android、iOS、macOS 原生壳与更新安装。
5. HarmonyOS 联机版、碰一碰和系统未成年人模式。
6. HarmonyOS 单机版、商店适配与素材。
7. 全端签名构建、下载中心、更新日志补齐、Cloudflare DNS 和上线验收。
