# HarmonyOS 应用市场原生截图清单

所有截图必须从正式签名的单机版真机画面直接截取，保留原始分辨率，不使用网页截图冒充。

1. `01-guided-start-phone.png`：手机竖屏，新存档默认引导 A，显示第一条连续任务与完整 HUD。
2. `02-sunrise-camp-phone.png`：日出时的连续 2.5D 海岸与已放置营火，展示地图细节。
3. `03-rain-building-phone.png`：雨天采集和建造预览，展示天气遮罩与真实放置物。
4. `04-snow-biome-phone.png`：寒冷高地和积雪/降雪，证明多地形不是单张背景图。
5. `05-diary-phone.png`：离线岛上日记编辑页，不能出现账号、好友或在线字样。
6. `06-free-mode-tablet.png`：平板横屏自由 B，展示更大视野、缩放/旋转与建筑管理。

每张截图旁保存同名 `.metadata.json`，至少记录设备型号、HarmonyOS 版本、应用版本、build、包名、拍摄时间和是否正式签名。
