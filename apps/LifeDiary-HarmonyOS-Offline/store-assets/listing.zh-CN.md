# 生活日记 offline

一句话简介：不注册、不联网，把日记、周期感受和戒烟历程留在自己的设备里。

## 应用介绍

生活不是任务清单，也不必每一天都很顺利。生活日记 offline 是一款完全单机的私人记录工具：可以写个人日记，记录周期日期、身体感受和疼痛程度，也可以用戒烟日记诚实记下坚持与反复。

应用不创建账户、不申请网络权限，所有内容默认只保存在当前设备。你可以随时导出 JSON 备份，也可以在新设备上自行导入。

## 主要功能

- 个人日记：用标题和正文安静记录今天。
- 周期记录：记录日期、感受与疼痛程度；预测仅作生活参考，不替代医疗建议。
- 戒烟日记：记录无烟天数、感受与反复，不用夸张成就刺激。
- 本机备份：自主导出、导入 JSON 文件。
- 未成年人模式：适配 HarmonyOS 系统未成年人状态；年龄设置完成时提示，可选择 7 天内不再提示或永久不再提示，并可在设置中恢复。

## 隐私说明

单机版不包含社区、好友、聊天、通行证或陪伴助手，不申请网络权限。卸载应用前请先导出备份，否则本机数据可能随应用一同移除。
